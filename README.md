# memento.engineering Homebrew tap

Command-line tools from [memento.engineering](https://memento.engineering).

```sh
brew install memento-engineering/tap/<formula>
```

| Formula | What it is |
|---|---|
| [`decisions`](https://github.com/memento-engineering/decisions) | Lint, index and search a decision register |

The tap carries **stable releases only**. Prereleases are published on each project's GitHub
Releases page, with checksums, and can be pinned from there.

Formulae are generated by each project's release workflow from the release's own checksums, so a
change made here would be overwritten by the next release. To report a problem with a formula,
open an issue on the project it installs.
